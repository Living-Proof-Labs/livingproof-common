# Contribute

Use the [development environment](development.md) and open a pull request in
[the source repository](https://github.com/Living-Proof-Labs/livingproof-common).
Report ordinary bugs or documentation problems through
[Help / report an issue](https://github.com/Living-Proof-Labs/livingproof-common/issues).

The shared standards are [collaboration-guidelines v6.0.0](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v6.0.0/AGENTS.md),
including its [manual recipe](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v6.0.0/docs/documentation-recipe.md)
and [independent review procedure](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v6.0.0/docs/independent-review.md).
Read them at that exact release; a link does not load instructions. Local additions
are in [this repository's AGENTS.md](https://github.com/Living-Proof-Labs/livingproof-common/blob/main/AGENTS.md).

This repository owns library behavior and consumer examples. Organization vision
and the manual directory belong at [Documentation home](https://docs.livingprooflabs.com/).
Keep dependency and release-workflow upgrades separate from guidance adoption.
No new CLI, plugin manager or simulator belongs in this library.
