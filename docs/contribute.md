# Contribute, help, and licensing

Follow [collaboration-guidelines v6.0.0](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v6.0.0/AGENTS.md)
and the [documentation recipe at that version](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v6.0.0/docs/documentation-recipe.md).
The [local instructions](https://github.com/Living-Proof-Labs/livingproof-common/blob/main/AGENTS.md)
record additions and exceptions. Native Task commands are listed in [Tasks](tasks.md);
[verification](verification.md) explains execution context and evidence limits.

Common owns its Python library interfaces and consumer identity behavior. It has
no command interface, plugin manager, simulator or capability contract.
The [documentation home](https://docs.livingprooflabs.com/) owns organization
vision and the manual directory. [LivingProof](https://docs.livingprooflabs.com/livingproof/)
and [Reporter](https://docs.livingprooflabs.com/livingproof-capability-report/)
own their consuming commands and behavior.

- [Source](https://github.com/Living-Proof-Labs/livingproof-common)
- [Help / report an issue](https://github.com/Living-Proof-Labs/livingproof-common/issues)
- [License: Apache-2.0](https://github.com/Living-Proof-Labs/livingproof-common/blob/main/LICENSE)

No established private security reporting destination is documented. Do not post
sensitive reports in public issues. Current manual and source-directory links are
navigation exceptions only; they do not change pinned guidance or dependencies.
